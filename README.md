# 三相异步电动机 / THE HEART OF DRIVE

一个单文件、可离线运行的 Three.js 3D 电机教学诊断实验台。虚构教学机型 **Y90S-4**（1.1 kW / 380 V △ / 2.2 A / 1400 r/min / 4 极 / 50 Hz），包含程序生成的三维电机、五路传感器、故障注入、SVM 教学判决、报警联动与电影演示。

## 运行

直接双击 `index.html`，或把它拖进 Chrome / Edge / Firefox。页面通过 `file://` 可完整运行，不需要服务器、不需要联网。

- Three.js 固定为 **r187**（`three@0.187.0`），通过静态 import map 内的 data URL 内嵌。
- 没有外部模型、贴图、HDR、字体或音频；全部几何、Canvas 纹理、声音和图表均在单文件内生成。
- WebGL2 不可用时显示失败说明，不会停留在加载层。

## 交互

- **启停**：断电、启动、停机、暂停机构；启动有真实冲击电流与镜头轻推，停机后按惯量惰走。
- **两种观察时钟**：AUTO（机构 30 r/min / 磁场 32.14 r/min）和 ULTRA（12 / 12.86），可切到 1× 查看真实 1500 r/min 磁场；时间轴可暂停、拖动，也可 ±1°/5°/15° 步进。
- **结构**：外观、机械切面、分层爆炸；再次点击“分层爆炸”会归位并恢复暂停前状态。切面下可开关鼠笼导条、气流和注释。
- **负载**：0–120% 拖动，转速、电流、转矩工作点与六特征同步更新。
- **六种工况**：正常、卡滞堵转、轴承磨损、转子断条、绕组过热、过载运行；报警带可配置延时、声光联动与保护停机。
- **五路传感器**：霍尔电流、增量式编码器、PT100、振动加速度、对射光电；点击后镜头飞向安装位置、被测部件脉冲高亮，并打开测量链说明。
- **镜头**：整机 / 剖面 / 磁场与转差 / 转子 / 传感器布局；窄屏下通过下拉框选择。手动拖动或滚轮会立即终止自动镜头。
- **数据视图**：14 个可放大数据卡；支持暂停实时刷新、复制 Markdown、导出 PNG、浏览器全屏。全屏数据大屏可整体进入全屏。
- **电影演示**：24 秒，覆盖整机、旋转磁场、爆炸结构、故障注入、报警和复位；任意点击可退出，并保留用户当前输入。
- **演示模式**：隐藏界面，只保留 3D 与退出提示。
- **声音**：默认静音；条件声、连续声、五音、慢速等模式均只用于教学，不模拟真实声压级。

### 快捷键

`R` 重置视角 · `Space` 暂停/继续机构 · `F` 磁场显示 · `C` 电影演示 · `E` 外观/爆炸 · `P` 演示模式 · `M` 声音 · `A` 注释 · `?` 帮助 · `Esc` 关闭浮层。输入框或按钮获得焦点时，空格等快捷键不会抢占其行为。

## 教学简化与已知限制

1. **转矩/SVM 都是教学模型，不是电机设计软件。** T(s) 由额定点、Tmax≈2.2Tn、s_m≈0.20 校准的平滑曲线拟合，起动段用简化冲击电流补偿；没有用有限元或完整双笼模型。
2. **热模型为单时间常数集中参数模型**（默认显示 ×10 加速，均为明确标记的演示加速）。考虑铜耗随电流变化、散热与温度告警；不模拟绕组分层温度、绝缘老化或环境变化。
3. **机械、电气、热参数均为教学设定。** Y90S-4 是虚构教学型号；铭牌、轴承型号、槽数、气隙等用于讲解，不代表真实产品参数。
4. **故障波形是确定性教学信号。** 轴承周期冲击、断条 2sf 边频、振动谱与 SVM 训练/混淆矩阵均为合成的教学样本；实时 SVM 判决是六特征中的二维线性化切面，用于展示判决边界、间隔和支持向量概念，并非工业级 RBF-SVM 训练。
5. **接线盒 △/Y 切换只做结构演示**，不会真正把运行中的电气模型从 △ 改编为 Y；界面和说明中已注明。
6. **光电脉冲频率是随展示转速缩放的演示值**：用来观察堵转时光电脉冲消失，不代表真实的每转脉冲计数。
7. **气隙 0.35 mm 在 3D 视图中有放大**，以便观察；切面和爆炸为教学剖切，不是制造图纸。
8. **过载工况**在 0–120% 滑杆内做教学设定；表中“3.5 A”是教学参考值，电流模型在约 112% 负载时约 2.4 A，优先保证额定点严格为 2.2 A 与模型自洽。超过 Tmax 的极限过载需要更大负载，未放进 120% 滑杆。
9. **无头验证环境的真实帧率不代表用户机器。** 本项目的截图与回归测试在软件 SwiftShader 下完成，帧率通常只有 1–5 fps；真实 GPU 上场景目标为接近 60 fps，AUTO 画质会在持续低帧率时自动降级。

## 实际验证记录

- 以 `file://` + `offline: true` 打开最终 `index.html`；无外部请求、无 JavaScript 异常。
- 1440×900、1366×768、1024×768、768×1024、390×844 均无横向页面溢出；桌面右侧面板在 1366 高度下使用内部滚动。
- 启停、惰走、暂停/继续、时间轴 ±1/5/15° 步进、负载拖动、温升、报警延时、保护停机、报警复位均通过浏览器自动回归。
- 五路传感器逐个点击：镜头移动到对应安装位置、对应部件高亮、标签/连线可见、详情表在桌面和移动端均无裁切。
- 14 张数据卡全部可以打开；表格数据修复后无空白；PNG 导出实际产生下载文件；Markdown 复制、全屏、复制数据和电影中断均通过测试。
- 24 秒电影各阶段通过受控时间轴检查；自然结束时覆盖层关闭、故障复位、电机回到运行命令状态。在极低软件渲染帧率下，恢复段可能仍在升速；正常帧率下恢复段为 4.4 秒，足够从重启升到额定转速。
- 所有几何、材质、图表、声音均为程序生成；最终单文件约 1.35 MB。
